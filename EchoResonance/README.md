# 🗼 Echo Resonance — Archotech Resonator & Pawn Perks

[![RimWorld 1.6](https://img.shields.io/badge/RimWorld-1.6-brightgreen.svg)](https://rimworldgame.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Echo Resonance is a RimWorld 1.6 mod introducing a long-term progression system driven by the **Archotech Resonator** and the **Echo Pool**.

## 📖 Concept Overview
- **Echo Pool:** Colony-wide currency accumulated through organic gameplay actions (skills, raids, masterwork items, rituals).
- **Archotech Resonator:** Single-build core structure that generates and anchors Echo points. If destroyed, unspent Echo is wiped out!
- **Attunement Pylons:** Up to 4 pylons per map to scale Echo accumulation up to x3.0.
- **Pawn Perks:** No hard slot caps! Costs scale exponentially ($1.6^{N-1}$) per pawn, with a 25% specialization discount for matching branches.
